{% comment %} Shared PWA head fragment. Included by every top-level template so the whole site is installable, not just one page. Everything here is per-section: the values come from the "pwa" context processor in 2048/pwa.py, which picks the section out of the request path. That is what lets /blog/, /sensors/ and /priorities/ install as separate home screen apps with their own name and icon. Careful with edits: these tags only work inside . Any stray text in the head — including a {# #} comment spanning more than one line, which Django does not strip — ends the head element and pushes the tags below it into the body, where Safari ignores them and Add to Home Screen falls back to a plain bookmark. {% endcomment %} {# Standalone display.
